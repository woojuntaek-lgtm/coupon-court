# 쿠폰 판정소

같은 60 대 40인데 결론이 정반대? — 범주형 데이터를 읽는 법을 손으로 체험하는 앱입니다. 명목형·순서형·수치형 분류, 우편번호 평균의 함정, value_counts로 찾는 입력 오류, 원그래프와 막대그래프, 가입 채널 × 재구매 교차표와 전체·행·열 백분율, 기대 빈도, 카이제곱 통계량과 자유도·p 값, 사람 수에 비례해 커지는 카이제곱(10명씩 vs 100명씩), 효과 없는 쿠폰 1,000번 실험, 코크란의 규칙과 피셔 정확 검정, 예이츠 보정, 원 핫 인코딩과 drop_first까지 담았습니다. 빅데이터 07 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 빈도: 쿠폰 사건 접수, 데이터 종류 분류, 우편번호 평균, value_counts와 정제, 원 vs 막대
- ② 교차표: 개수·전체 %·행 %·열 % 전환, 퀴즈 ①(기대 빈도 60), 칸별 기대 빈도와 관측 비교
- ③ 카이제곱: 차이를 그냥 더하면 0, (O−E)²/E, 자유도 1 슬라이더와 p 값(예이츠 보정 선택), 사람 수 슬라이더, 1,000번 모의실험, 코크란의 규칙과 피셔
- ④ 원 핫: 1·2·3 숫자 인코딩의 함정, get_dummies 공장(drop_first), 퀴즈 ②(7개), 순서형 인코딩, 파이썬 코드, 세 줄 정리, 생각해 볼 질문
