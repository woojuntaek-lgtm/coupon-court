🔢 서울 = 1, 부산 = 2, 대구 = 3 ?

지역 → 숫자로 바꾸면 모델은 이렇게 읽을 수 있습니다 서울(1) + 부산(2) = 대구(3) 대구(3) = 서울(1) × 3 평균 지역 = (1+2+3)/3 = 부산(2)
순서도 크기도 없는 지역에 크기가 생겨 버립니다. 그래서 명목형은 원 핫 인코딩!

❓ 퀴즈 ②

지역 열에 서울·부산·대구·광주 4종류, 등급 열에 VIP·골드·일반 3종류가 있습니다. 두 열을 모두 원 핫 인코딩하면 열이 몇 개 생길까요?

📶 순서형은 순서를 살려서

만족도 → 순서 인코딩 불만족 → 1 보통 → 2 만족 → 3 순서가 진짜로 있으니 1 < 2 < 3이 뜻을 가집니다.
명목형은 원 핫, 순서형은 순서 번호도 방법 — 데이터의 종류에 맞게 고릅니다.

🐍 파이썬으로 한 번에

import pandas as pd, seaborn as sns from scipy.stats import chi2_contingency df["지역"].value_counts() # ① 세기 tab = pd.crosstab(df["채널"], df["재구매"]) # ② 교차표 pd.crosstab(df["채널"], df["재구매"], normalize="index") # 행 % chi2, p, dof, expected = chi2_contingency(tab) # ③ 검정 sns.countplot(data=df, x="채널", hue="재구매") # ④ 그림 pd.get_dummies(df, columns=["지역", "등급"]) # 모델 입력
채널 표의 실제 결과 (scipy 기본: 예이츠 보정) chi2 = 7.143, p = 0.0075, dof = 1 expected = [[44.1, 45.9], [53.9, 56.1]] ← 모든 칸 5 이상, 코크란 OK
세고, 나누고, 검정하고, 그려 본다 — 범주형 탐색의 기본 순서입니다.

📌 세 줄 정리

  1. 범주형은 평균 대신 빈도와 비율로 요약하고, 빈도표로 입력 오류도 찾는다.
  2. 교차표는 질문에 맞는 합계로 나누고, 카이제곱은 관측과 기대 빈도의 차이로 독립인지 판정한다.
  3. 카이제곱은 표본 크기에 비례해 커지니 p 값과 차이의 크기를 함께 보고, 모델에는 원 핫으로 넣는다.
